# Minhas Aulas · Anhanguera

PWA mobile-first para organização das aulas do segundo semestre de 2026.

## Recursos

- agenda semanal e próxima aula;
- calendário por disciplina;
- controle de aulas concluídas e anotações offline;
- listas de chamada com nomes abreviados por iniciais;
- critérios de aprovação, salas e horários;
- links acadêmicos;
- informações privadas armazenadas apenas no navegador;
- instalação no iPhone e funcionamento offline.

## Uso no iPhone

1. Abra o endereço publicado usando o Safari.
2. Toque em **Compartilhar**.
3. Selecione **Adicionar à Tela de Início**.
4. Abra o aplicativo uma vez com internet para concluir o cache offline.

## Privacidade

O e-mail institucional e a senha do Wi-Fi não estão no código. Esses dados devem ser preenchidos na seção **Ajustes** e ficam somente no armazenamento local do aparelho.
